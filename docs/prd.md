# Novel Studio — 产品方案

AI 小说创作工作室：写作 → 封面 → 推文视频 → 多平台分发。

## 定位

不是"AI 批量产文机"，而是"AI 辅助创作 + 发布管理"工具：
AI 负责提速，人负责质量。这一定位同时规避平台对纯 AI 文的风控风险。

## 核心架构认知

设定库（人物/世界观/时间线/伏笔）是所有模块的共享资产：

- 写作引擎：设定注入上下文，保证长篇一致性
- 封面生成：人物卡 → 视觉提示词
- 推文视频：章节 → 分镜脚本
- 人物卡同时存文字设定与视觉设定（参考图/seed），保证封面与视频形象统一

## 路线图

### v0.1（当前切片）✅

- 作品/章节管理（SQLite 本地存储，自动保存）
- TipTap 编辑器
- LLM 流式续写（OpenAI 兼容协议，开发期用 DeepSeek）
- 模型设置（接口地址 / Key / 模型名）

### v0.2 ✅

- 设定库：人物卡 / 世界观 / 词条，关键词触发 + 常驻注入，明细可见
- 划词改写/润色/扩写（浮动工具条，流式替换）
- 导出 txt（系统保存对话框，整书按章拼接）
- 滚动前情摘要（每章可生成摘要，续写时自动注入，预算控制）

### v0.3 ✅

- ✅ 封面生成：生图 API（火山方舟/即梦）+ 程序排版书名，封面历史管理
- ✅ 全书体检：设定冲突/时间线/伏笔台账/逻辑漏洞，流式报告 + 历史存档
- ✅ 批量补齐章节摘要（带进度条，体检的数据地基）

### v0.4（第一刀已落地）

- ✅ 推文视频流水线（静图运镜模式）：口播稿（流式+设定注入）→ 分镜（JSON）→
  逐镜生图（可单镜重绘）→ 火山 TTS 配音（按句时长对齐字幕）→ ffmpeg 合成竖屏短片
- ✅ 视频工坊视图（分镜表/进度/预览播放），导航栏「视频」已点亮
- 待后续切片：图生视频（可灵/即梦）、任务队列面板、BGM/片头片尾

### v0.5+

- 视频平台官方 API 分发（抖音开放平台 / TikTok / YouTube）
- 小说平台半自动发布助手（自动填充，人工点发布）
- 云端服务：账号 / 点数计费（视频生成 API 成本高，按量收费）

## 体验指标（验收用数字说话）

| 指标 | 目标 |
|---|---|
| AI 续写首字延迟 | < 1.5s（含网络） |
| 章节切换 | < 100ms |
| 自动保存 | 无感（防抖 800ms） |
| 封面出图 | < 15s |

## 平台政策风险备忘

- 番茄/起点等对纯 AI 生成内容有限制：工具定位 AI 辅助，用户需人工把控
- 平台封书主要路径是编辑审核 + 读者举报，而非文本检测
- 上传功能永不触碰逆向接口
