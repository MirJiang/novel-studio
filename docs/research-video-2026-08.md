# 视频流水线方案调研（2026-08）

> 背景：讨论"文生视频 vs 图生视频"路线后做的三线调研（国内模型横评 / B站知乎实战帖 / GitHub 开源方案）。
> 结论先行：**现行"分镜生图 → 图生视频 → 配音 → 合成"架构不改，这就是 2026 年行业共识**；
> 要补的是角色一致性工程、防漂移默认策略、剪映草稿出口。

## 一、路线结论：纯文生视频多镜头一致性仍不可用

- 2026 年所有漫剧/推文工作流（B站教程、GitHub 头部项目）无一例外走 i2v 或"参考生视频"；
  纯 t2v 逐镜独立抽样，角色长相/服装/画风逐镜漂移，只适用于无连续角色的空镜
- 改善方向是"多图参考/角色库"而非纯 t2v：Seedance 2.0（≤9 图参考）、可灵 3.0 Omni（主体参考）、
  Vidu 主体库（多角度参考图，漫剧圈角色一致性口碑最硬）
- GitHub 活跃小说转视频项目（Toonflow 13.9k / 火宝短剧 14k / ArcReel 4k）清一色
  "分镜生图→图生视频"，角色一致性=角色资产库+多图参考——与本项目人物卡参考图路线一致

## 二、模型格局（2026-08，价格来自公众号口径，落地前以官方定价页为准）

| 模型 | 要点 | 价格口径 |
|---|---|---|
| Seedance 2.0/2.5（火山方舟） | ≤9 参考图+3 视频+3 音频；4–15s；原生音画同步；2.5 主打 30s 长叙事 | 约 1 元/秒 |
| 可灵 Kling 3.0 Omni | 动作自然度第一；图生+主体参考双轨防漂移 | 最贵，约 4 元/5s 720P |
| Vidu Q2/Q3（生数） | "参考生视频"首创，主体库跨镜头角色不崩，漫剧圈口碑最硬 | 免费 30s/月起 |
| MiniMax H3 | 2026-08-03 开源，4090 可本地跑；赛璐璐风格保持有实测背书；音频参考不稳 | 0.8 元/秒（2K） |
| 万相 Wan3.0 | 2026-08-06 公测，单段 30s；实测沉淀少，观望 1–2 个月 | 0.6 元/秒（720p） |

圈内口诀："可灵动作好、即梦生态好、海螺参考控制好、Vidu 角色一致性好"，成熟创作者按镜头类型切工具。

## 三、风格漂移实战结论（B站 7.2 万播放痛点视频等）

- 首帧即风格锚点；**首帧人脸不清晰会串脸**；>5s 长镜头尾段风格衰减 → 业界统一用 3–5s 短镜拼接
- 崩坏主因是运动幅度过大 → prompt 加"轻微/缓慢"收敛词 + 固定风格词贯穿全片
- 参考图不是越多越好（首帧+多张角色表同塞反而漂移）→ ≤3 张策略恰好
- 能用首尾帧就不用单帧；崩了就重抽（重抽率是隐性成本乘数）
- 动漫/赛璐璐风比真人风耐崩，这也是推文圈偏爱动漫风的原因之一

## 四、成本账

- 单条 1–3 分钟推文视频现金成本普遍几元~二三十元，大头是图生视频积分 × 重抽率
- 个人整部漫剧"不到 80 块"口径常见；静图运镜/图生视频双 mode 分层是市场验证过的打法

## 五、可借鉴的工具设计（按优先级）

1. **导出剪映草稿**（draft_content.json）——头部工具（文镜画师/聚星文社/ArcReel/TypeTale）共同卖点，精剪留给剪映
2. **角色三视图**：AI 生成正/侧/背设定图 → 每镜自动携带（比单图参考明显更稳）——在现有 ref_image 基建上升级
3. **人物↔音色绑定**：多角色对话每人固定声音（文镜画师/万象"固定音色"）
4. **分镜 prompt 工程**：Seedance 时间轴格式（0-3秒…+【声音】+【参考】@图N）+ 运镜关键词表，
   参考 github.com/liangdabiao/Seedance2-Storyboard-Generator（2.1k star 纯 prompt 资产）
5. 画风预设库（次元姬"62 种画风"）——可延伸现有风格库机制
6. 字幕双路：TTS 时间戳（快）/ faster-whisper 转写（准）可切换（MoneyPrinterTurbo 设计）
7. 本地开源（Wan2.2 经 LightX2V 8GB 显存可跑）对网文作者用户群不现实，维持 API 优先；
   可选方向是对接用户自装 ComfyUI 当外部服务
