## 二、AI 味到底是什么（2026-07 一手报道深挖，编辑/读者/作者/平台四方定义）

AI 味不是单一特征，是四层指纹的叠加（证据链见下）：

1. **词汇句式层**（读者最先感知）：圈内公认（编辑程淼，经济观察报）——无意义环境/心理描写、
   大量短句、「不是……而是……」、过多破折号；下游分发商补充硬指纹：**AI 不会数数**
   （"角色说了四个字，下一行写'对这五个字震惊'"——分词逻辑数错字数）
2. **叙事结构层**（编辑判定核心，澎湃编辑访谈五大特征）：语言华美而空洞（一句话形容词>3个、
   "数着第37根雨丝划过屏幕"）；逻辑 bug（父母双亡却给爸爸打电话）；**爱做加法破坏节奏**
   （"老手往死里做减法，AI 往死里做加法"——惊悚时刻插大段外貌描写）；不主动推进剧情
   （环境+名词解释+遇人+心声=写了很多零推进）；无法情感共鸣（拼凑逻辑表达不出情绪）
3. **根因层**（科学网 2025-10）：LLM 每步选"最安全"的词 → 高频=安全=AI味；
   作者程淼："为了不被说AI味，得特意避开脑子里最先跳出来的词"。长篇崩坏主因是上下文能力
   （记不住几百万字背景），非文笔；Humanizer Skill 12万下载也压不住——"为打破套路，AI 会创造新套路"
4. **平台治理层**（2026 现状）：番茄 6 月拒签低质 10 万本+处置 4 万本，"AI粗制滥造"为四类严禁
   行为之一；平台"AI鉴AI"+读者举报（举报项就有"AI水文"）；检测不可靠（同书不同章 0%/44%/87%，
   朱雀官方承认误报）；人类短句风作者被误骂AI、晋江站长原创诗被 DeepSeek 判为 AI——行业新平衡
   = AI 辅助 + 人工主导（晋江仅放行校对/要素/粗纲三级辅助，起点拒收一切 AI 文）

对本项目三层方案的校验：层1（词表句式）✅ A1/A2/A3 覆盖；层2 的节奏加法病 ✅【章法】prompt
（每场戏目标/阻碍/变化 + 章末停在那一拍）+ DESLOP 第4条，逻辑 bug ✅ 摘要链+全书体检兜底；
层4 ✅ 产品定位本就是 fill-only 人工点发布。
2026-08-21 追加落地（编辑访谈五特征的补漏）：生成 prompt 加「描写做减法」禁令（紧张场景禁插
静态描写 + 形容词一句至多两个，对应"爱做加法"与"华美空洞"）；DESLOP 加第 6 条删凑字水段；
全书评分通读评注【问题】栏与总评【文笔评价】栏加「数量/称谓硬伤」专项（AI 不会数数类指纹）。

## 三、AI 味指纹（社区共识清单，源自 story-deslop 禁用词表）

**一级禁用词（出现即替换）**：
- 情态类：仿佛、好像、犹如、宛若、一丝、一抹、些许、几分、隐约
- 动作类：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- 表情类：眼中闪过、嘴角勾起（弧度/一抹笑）、眉头微皱、眉眼低垂、瞳孔（骤缩/微缩）
- 心理类：心中一动/一沉/一紧、心底涌起、内心深处、说不上来、难以言喻
- 句尾类：……般的、……似的、……的气息、……在空气中（弥漫/凝固）

**二级替换（慎用，高频即换）**：瞬间→一瞬/刹那；闪过→掠过；复杂→说不上来；情绪→心气/心思；知道→清楚/明白

**指纹句式**：三句以上排比连用；"不是 A，而是 B"高频复现；每段结尾总结升华；"他感到 / 那是一种……的感觉"；环境静得能听见针落

**叙事级指纹**（oh-story Issue #147：约束应从词汇级升到结构级）：段落长度均匀无呼吸、描写疏密无分布、情绪曲线无波峰波谷、爽点密度间隔机械。

## 四、核心方法论（story-deslop 六门禁 + 三遍法）

**写完后的六门禁检查**（每门独立判断，命中才改，改最少效果最大）：
A 禁用词替换（词表硬扫）→ B 句式去套路（排比/对仗/"不是而是"）→ C 心理描写外化（"他感到恐惧"→ 手在抖）→
D 节奏打碎（超长复合句拆短、均匀段落重排）→ E 对话去腔调（删"××说道"标签、口语颗粒）→ F 结尾去升华（删总结句）。

**三遍去 AI 法**：Pass1 去泛化（抽象→具体名词动词）→ Pass2 去书面化（工程腔→口语颗粒）→ Pass3 回人味（噪点：语气词、不完美表达、前文细节呼应）。

**预防约束（生成时注入，比写后补救便宜）**：Show Don't Tell 落到"情绪一律用动作/生理反应/对话行为外化"；
比喻从角色职业/生活取材；对话标签能省则省；段落长短错落（1~3 句短段穿插）；章末停在动作/对话，禁止总结升华。

**真人写作基准（对标表）**：对话标签率 <40%、排比从不连续 3+ 句、情绪 100% 动作展示、每千字允许 1~2 个语气词。

## 五、落地到 Novel Studio（行动清单）

现状诊断：
- `SYSTEM_PROMPT`（commands.rs）只有一句"去 AI 味是硬要求"——有原则、无词表、无自查标准，LLM 无从执行
- 续写/划词/批量写章/助手改写全部**写完即落库**，无去味 pass
- 已有可复用基建：`scan_banned_words`（合规扫描：词表+上下文+一键入队改写）、风格卡蒸馏、批量写章巡检简报、全书评分文笔评价栏
- 风格卡（styles.guide）是 LLM 抽象描述，无真人原文锚点注入写作

行动清单（按成本排序）：
- [x] **A1 写作 prompt 负面清单段**（零成本，全路径生效）：SYSTEM_PROMPT / TRANSFORM / 助手改写
      注入【去AI味】硬约束段：一级禁用词表 + 指纹句式禁令 + 情绪外化/章末禁升华（2026-08-21 落地，D29）
- [x] **A2 AI 味本地扫描**（零 LLM 成本）：`scan_banned_words` 返回扩为 ScanResult（含 total_words），
      体检页内置词表一键填入 + 命中密度（处/万字）+ 高频词 Top8（2026-08-21 落地）
- [x] **A3 划词「去AI味」**（一遍 LLM，复用 ai_transform 流式管线）：mode=deslop，六门禁压缩成 DESLOP_REQUIREMENT（2026-08-21 落地）
- [x] **A4 批量写章去味 pass**（成本 ×2，默认关）：设置项 batch_deslop，每章生成后自跑 deslop_chapter_text，
      失败回退原文不中断（2026-08-21 落地）
- [x] **A5 风格卡人味锚点**：styles.example（蒸馏时摘的真人原文片段）作为【真人语感参照】
      注入写作 prompt few-shot（2026-08-22 落地：style_section 追加 example 头 200 字，"模仿语感不抄内容"；
      同时 SYSTEM_PROMPT 加【人味】段——句长波动/词汇意外性/毛边，DESLOP 加第 8 条回人味加法）
- [ ] **A6 范例替换表内置**：真人高频替换表（深吸一口气→胸口起伏了一下 等）供 A3/A4 改写时参照
- 检测侧结论（2026-08-22 朱雀实测后定调）：**不做本地检测器**（Binoculars 等开源方案留档）——
  检测交给朱雀（免费、番茄同款），生成侧人味是主业；实测对话段 AI 值 0.4~0.66 vs 描写段 0.99，
  对话/描写节奏已加进写作 prompt（连续静态描写≤两段必打断），体检页加对话占比统计（健康区间 20%~45%）

## 六、风险与边界

- 提示词去 AI 味"治标不治本"的争议（[X @dotey](https://x.com/dotey/status/2009649023943082449)）：单靠 prompt 不稳定，
  组合拳（预防+改写+扫描定量）是社区验证过的稳定解
- 去 AI 味 pass 会轻微损失信息密度与"工整"，风格卡若绑定古龙/晋江等强风格，约束需让位于风格卡
- 外部 AI 检测（腾讯朱雀）暂不接入：在线服务无稳定 API，本地词表密度指标已够自检用
